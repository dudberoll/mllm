# Как в работе считается экспонента Херста

## Идея

В работе последовательность логарифмов вероятностей токенов рассматривается как одномерный временной ряд

\[
x_1, x_2, \dots, x_T,
\]

где \(x_t\) — это `log p_t` для очередного токена в процессе генерации.  
По этому ряду оценивается экспонента Херста \(H\), чтобы понять, насколько динамика уверенности модели является шумовой или, наоборот, имеет устойчивую внутреннюю структуру.

## Основные шаги вычисления

### 1. Построение профиля ряда

Сначала из исходного ряда вычитается среднее значение, после чего строится накопленная сумма:

\[
y_k = \sum_{t=1}^{k}(x_t - \bar{x}),
\]

где \(\bar{x}\) — среднее значение ряда лог-вероятностей.

Этот шаг переводит исходный ряд в так называемый профиль флуктуаций.

### 2. Выбор масштабов

Далее выбирается набор масштабов \(s\), то есть размеров окон, на которых будет анализироваться структура ряда.  
В коде используется несколько масштабов, распределенных логарифмически от малых окон к более крупным.

### 3. Оценка флуктуаций на каждом масштабе

Для каждого масштаба \(s\):

- профиль \(y\) разбивается на непересекающиеся окна длины \(s\);
- в каждом окне вычисляется дисперсия значений профиля;
- затем по всем окнам данного масштаба считается среднеквадратичная флуктуация:

\[
F(s) = \sqrt{\frac{1}{N_s}\sum_{i=1}^{N_s}\mathrm{Var}(y_i)},
\]

где \(N_s\) — число окон масштаба \(s\), а \(y_i\) — значения профиля внутри \(i\)-го окна.

### 4. Оценка наклона в логарифмических координатах

После этого строится зависимость между масштабом и величиной флуктуаций:

\[
\log F(s) \sim H \log s.
\]

Экспонента Херста \(H\) оценивается как наклон линейной регрессии в лог-лог координатах:

\[
H = \text{slope}\bigl(\log s,\ \log F(s)\bigr).
\]

В реализации полученное значение дополнительно ограничивается диапазоном \([0,1]\).

## Интерпретация

Полученный показатель \(H\) интерпретируется стандартным образом:

- \(H \approx 0.5\) — поведение близко к случайному шуму;
- \(H > 0.5\) — наблюдается персистентность, то есть соседние участки ряда склонны продолжать уже заданную динамику;
- \(H < 0.5\) — наблюдается антиперсистентность, то есть ряд чаще меняет направление.

В контексте нашей работы это означает:

- более высокий \(H\) соответствует более связанной и структурированной динамике уверенности модели;
- слишком низкий или слишком высокий \(H\) может свидетельствовать о выходе модели в патологический режим генерации;
- поэтому \(H\) может использоваться как диагностическая метрика или как основа для регуляризации.

## Практическая схема, используемая в коде

В прикладном виде вычисление выглядело так:

1. взять активные `logprobs` по маске;
2. вычесть среднее и построить кумулятивную сумму;
3. выбрать несколько масштабов;
4. на каждом масштабе посчитать флуктуации;
5. построить линейную регрессию в координатах \(\log s\) и \(\log F(s)\);
6. взять наклон как оценку \(H\).

## Короткая формулировка для доклада

В работе показатель Херста вычисляется по последовательности логарифмов вероятностей токенов, рассматриваемой как временной ряд. Сначала из ряда строится профиль через вычитание среднего и накопленную сумму, затем на нескольких масштабах оцениваются флуктуации этого профиля. После этого в логарифмических координатах строится зависимость между масштабом окна и величиной флуктуации, а наклон линейной регрессии интерпретируется как оценка экспоненты Херста. Значения около \(0.5\) соответствуют шумовому режиму, значения выше \(0.5\) указывают на персистентность, а значения ниже \(0.5\) — на антиперсистентность.
