# Spearman Correlation Between Hurst Metrics and Quality

Дата составления: 2026-06-09

Этот файл описывает, как математически считалась связь между Hurst-based метриками траектории и качеством ответа.

## 1. Объект анализа

Единицей анализа была одна student-generated trajectory:

\[
\tau_i,\quad i=1,\dots,N.
\]

Для каждой траектории были доступны:

- последовательность student logprobs:

\[
\ell^{(s)}_{i,1:T_i}
\]

- последовательность teacher logprobs на той же student-generated trajectory:

\[
\ell^{(t)}_{i,1:T_i}
\]

- mask активных токенов:

\[
m_{i,1:T_i} \in \{0,1\}
\]

- качество ответа:

\[
y_i.
\]

В качестве \(y_i\) использовался reward или binary correctness:

\[
y_i \in \{-0.1,\ 0.9\}
\]

или

\[
y_i \in \{0,1\}.
\]

Большие значения \(y_i\) означают более качественный ответ.

## 2. Hurst Metric Per Trajectory

Для каждой траектории сначала бралась активная часть logprob-последовательности:

\[
x^{(s)}_i =
\left\{
\ell^{(s)}_{i,t}: m_{i,t}=1
\right\}.
\]

Затем по этой последовательности считался показатель Херста:

\[
H^{(s)}_i = H(x^{(s)}_i).
\]

Аналогично для teacher logprobs:

\[
x^{(t)}_i =
\left\{
\ell^{(t)}_{i,t}: m_{i,t}=1
\right\},
\]

\[
H^{(t)}_i = H(x^{(t)}_i).
\]

В простейшем global варианте анализировались признаки:

\[
H^{(s)}_i,
\quad
H^{(t)}_i,
\quad
|H^{(s)}_i - H^{(t)}_i|.
\]

## 3. Windowed Hurst Features

Для windowed-анализа активная часть траектории делилась на \(K\) окон:

\[
x_i = [x_{i}^{1}, x_{i}^{2}, \dots, x_{i}^{K}].
\]

Для каждого окна отдельно считался Hurst:

\[
H^{(s),k}_i = H(x^{(s),k}_i),
\quad
H^{(t),k}_i = H(x^{(t),k}_i),
\quad
k=1,\dots,K.
\]

После этого строились trajectory-level признаки:

### Mean Absolute Hurst Difference

\[
f^{\text{mean\_abs}}_i
=
\frac{1}{K}
\sum_{k=1}^{K}
\left|
H^{(s),k}_i - H^{(t),k}_i
\right|.
\]

### Max Absolute Hurst Difference

\[
f^{\text{max\_abs}}_i
=
\max_{k}
\left|
H^{(s),k}_i - H^{(t),k}_i
\right|.
\]

### Standard Deviation of Hurst Difference

\[
d_i^k = H^{(s),k}_i - H^{(t),k}_i.
\]

\[
f^{\text{std\_diff}}_i
=
\mathrm{std}_{k}(d_i^k).
\]

### Student Hurst Variability

\[
f^{\text{std\_s}}_i
=
\mathrm{std}_{k}(H^{(s),k}_i).
\]

### Teacher-side Hurst Variability

\[
f^{\text{std\_t}}_i
=
\mathrm{std}_{k}(H^{(t),k}_i).
\]

Именно \(f^{\text{std\_t}}\) и \(f^{\text{std\_s}}\) оказались наиболее сильными offline-сигналами качества.

## 4. Spearman Correlation

Для выбранного Hurst-признака:

\[
f_i,\quad i=1,\dots,N
\]

и качества:

\[
y_i,\quad i=1,\dots,N
\]

считалась корреляция Спирмена:

\[
\rho_s(f,y)
=
\mathrm{corr}_{Pearson}
\left(
\mathrm{rank}(f),
\mathrm{rank}(y)
\right).
\]

То есть сначала значения заменялись их рангами:

\[
R(f_i) = \mathrm{rank}(f_i),
\]

\[
R(y_i) = \mathrm{rank}(y_i).
\]

Затем по этим рангам считалась обычная корреляция Пирсона:

\[
\rho_s
=
\frac{
\sum_{i=1}^{N}
\left(R(f_i)-\overline{R(f)}\right)
\left(R(y_i)-\overline{R(y)}\right)
}{
\sqrt{
\sum_{i=1}^{N}
\left(R(f_i)-\overline{R(f)}\right)^2
}
\sqrt{
\sum_{i=1}^{N}
\left(R(y_i)-\overline{R(y)}\right)^2
}
}.
\]

Интерпретация:

- \(\rho_s > 0\): большие значения Hurst-признака связаны с более высоким качеством;
- \(\rho_s < 0\): большие значения Hurst-признака связаны с более низким качеством;
- \(\rho_s \approx 0\): монотонной связи почти нет.

## 5. Почему Использовался Spearman, А Не Pearson

Мы использовали Spearman correlation, потому что в этой задаче не было оснований ожидать линейную зависимость между Hurst-метрикой и качеством.

Причины:

- reward/correctness дискретны;
- распределения Hurst-признаков не обязаны быть гауссовыми;
- rollout-ы содержат выбросы по длине и качеству;
- связь может быть монотонной, но нелинейной;
- для анализа важно понять, упорядочивает ли метрика траектории по качеству.

Поэтому Spearman отвечал на более подходящий вопрос:

```text
Если Hurst-признак растет, качество в среднем тоже растет или падает?
```

а не на более жесткий вопрос:

```text
Описывается ли связь прямой линией?
```

## 6. Partial Spearman Correlation

Для проверки, что Hurst-сигнал не является просто прокси для других факторов, считалась partial Spearman correlation.

Пусть:

\[
f_i
\]

это Hurst-признак, например \(std_t\), а

\[
y_i
\]

это reward или correctness.

Также есть набор контролируемых переменных:

\[
Z_i =
[
KL_i,\ n^{active}_i,\ var\_diff_i,\ acf1_i
].
\]

Partial Spearman считался так:

1. Все переменные заменялись рангами:

\[
R(f_i),\quad R(y_i),\quad R(Z_i).
\]

2. Ранги Hurst-признака регрессировались на контролях:

\[
R(f_i) = a_f + b_f^\top R(Z_i) + \epsilon^f_i.
\]

3. Ранги качества регрессировались на тех же контролях:

\[
R(y_i) = a_y + b_y^\top R(Z_i) + \epsilon^y_i.
\]

4. Затем считалась Pearson correlation между остатками:

\[
\rho_{partial}
=
\mathrm{corr}_{Pearson}
\left(
\epsilon^f,\ \epsilon^y
\right).
\]

Иными словами, partial Spearman отвечает на вопрос:

```text
Связан ли Hurst-признак с качеством после удаления эффекта KL, длины и других динамических дескрипторов?
```

## 7. Как Это Интерпретировалось В Экспериментах

Если обычная Spearman correlation была положительной, это означало:

\[
f_i \uparrow
\quad \Rightarrow \quad
y_i \uparrow
\]

в среднем по ранговому порядку.

Если partial Spearman оставалась положительной после контроля:

\[
KL,\quad n^{active},\quad var\_diff,\quad ACF1,
\]

то Hurst-признак нес дополнительную информацию о качестве, не сводимую к этим факторам.

В offline-анализе были получены такие ключевые выводы:

- global `hurst_diff` на всей последовательности был слабым сигналом;
- windowed `std_diff` был сильнее global Hurst-diff;
- разложение сигнала показало, что `std_t = std(H_t^k)` и `std_s = std(H_s^k)` сильнее, чем `std_diff`;
- положительный знак корреляции означал, что эти величины являются диагностическими признаками хороших траекторий, а не штрафами, которые нужно минимизировать.

## 8. Короткая Формулировка Для Доклада

Для каждой траектории мы считали Hurst-based признак, например \(std_t\): делили последовательность teacher logprobs на окна, считали показатель Херста в каждом окне и брали стандартное отклонение этих значений. Затем мы сравнивали этот признак с качеством ответа через корреляцию Спирмена. Для этого значения признака и reward заменялись рангами, после чего считалась обычная корреляция Пирсона между рангами. Такой подход выбран потому, что качество дискретно, данные содержат выбросы, а связь между Hurst-метриками и reward не обязана быть линейной. Дополнительно мы считали partial Spearman correlation: удаляли влияние KL, длины ответа, variance и ACF1, а затем проверяли, остается ли связь Hurst-признака с качеством.
